# 応援ページの素材

このフォルダに、下の**7つのファイル名で**画像を置いてください。
置くまでの間もページは完全に動きます（飾りが出ないだけ）。

| ファイル名 | 何の絵か | どこに出るか |
| --- | --- | --- |
| `support-bg.webp` | 水色の水と泡の淡い背景 | 応援ページ全体の地（z-index 1） |
| `thanks-bg.webp` | お礼ページ用の淡い背景 | お礼ページ全体の地（z-index 1） |
| `hedgehog-support.png` | **ピンク**のハートをかかえたハリネズミ | 応援ページの主役（z-index 5） |
| `hedgehog-thanks.png` | **青**のハートをかかえて喜ぶハリネズミ | お礼ページの主役（z-index 5） |
| `support-water-decoration.png` | 水・泡・ガラス | 右下から入ってくる飾り（z-index 2） |
| `support-fruit-decoration.png` | 葡萄・葉・蔓 | 左上から入ってくる飾り（z-index 3） |
| `support-celebration.png` | ハート・星・紙吹雪 | お礼ページの上に重ねる演出（z-index 6） |

## 気をつけること

- **素材そのものを加工しないでください。** 明るさや大きさの調整は
  すべて CSS 側（`src/styles.css` の「応援ページ」ブロック）でやっています。
  `opacity` とマスクで、文字が読める濃さまで落としています。
- 背景は**中央がすいている**絵のほうが向いています。まん中に本文が載るので。
- 飾りは端から入ってくる構図が前提です。中央を丸く囲む構図だと、
  文字の居場所がなくなります。
- ファイル名が違うと出ません。拡張子（`.webp` / `.png`）も合わせてください。

## 置いたあとの確認

```
npm run build && npm test
```
