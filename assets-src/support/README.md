# 応援ページの素材

**ここは元画像の置き場所です。ここのファイルは配信されません。**

置いたあと、次を1回走らせてください。

```
node tools/optimize-assets.mjs
```

（`Executable doesn't exist` と出たら `npx playwright install chromium` を先に。
すでにどこかにある場合は `CHROMIUM_PATH=/path/to/chromium` を頭に付けても動きます）

長辺1200px・webp に落としたものが `public/assets/support/` にできます。
配られるのはそちらです（合計 18.7MB → 0.96MB になりました）。

置くときの名前は下の表のとおり。**拡張子は `.png` でも `.webp` でも大丈夫です**
（変換のときに揃えます）。素材が無くてもページは完全に動きます（飾りが出ないだけ）。

**お礼ページの背景（`thanks-bg`）は要りません。** CSS のグラデーションで描いています。

### つくる側に「ひょっこり」出るもの

こちらは飾りではなく**場面**です。何かが起きた瞬間だけ出て、用が済むと消えます。
ずっと出ているものは1つもありません。

| ファイル名 | 何の絵か | いつ出るか |
| --- | --- | --- |
| `hedgehog-empty.png` | 寝ている子 | まだ写真を選んでいないとき（選んだ瞬間に消える） |
| `hedgehog-waiting.png` | コーヒーの子 | AI の読み込みを待っているあいだ |
| `hedgehog-saved.png` | 手を振る子 | 保存できたとき |
| `hedgehog-help.png` | 歩いている子 | つかいかたシートの冒頭 |

**ステップ2（背景をけす）には置きません。** あそこは、とうめいになったかを
目で判定する画面なので、横に色のついた絵があると判断が鈍ります。
市松の下じきをテーマに追随させなかったのと同じ理由です。
ここは検証（`tests/run.mjs` の「つくる側のハリネズミは、場面のときだけ」）で見張っています。

**書き出しの大きさは枠に合わせています。** 応援ページの主役は 560px、
ひょっこり出るほうは 420px（出る枠が 72〜84px しかないため）。
1200px のまま配ると1枚 300KB になり、見た目は何も変わりません。
上限は `tools/optimize-assets.mjs` の `MAX_EDGE_BY_FILE` にあります。

## 水の輪（`support-celebration`）の置きかた

この素材は一度「使わない」と判断して外し、あとで戻したものです。
外した理由は絵ではなく**置きかた**でした。記録として残します。

- **最初の失敗**：画面いっぱい（`background-size: cover`）に敷いた。
  絵は中央がまるく空いた「輪」なので、画面いっぱいに引き伸ばすと
  輪の左右の腕がパソコンの広い余白に散らばり、水の塊が並んで見えた。
- **2番目の失敗**：列に合わせたが、上端を `top: 0` にした。
  輪のいちばん濃いところがステップ表示（1・2・3）に重なり、
  「完了」の文字が泡に埋まった。
- **3番目の失敗**：列に寄せすぎた（`+130px`）。輪の中央がカードに隠れ、
  左右に水の塊が2つ浮いているように見えた。**輪だと分からない大きさなら、
  輪として置く意味がない。**
- **いまの形**：`top: 132px`（＝カードの上端）から、
  幅は `min(--page + 300px, 98vw)`、`opacity: 0.34`。
  広げたぶん薄くしています。**大きさと濃さの両方を上げると、ただの広告になります。**
  カードを囲む輪として成立し、下側はマスクで消しています
  （垂れてくると、ただの汚れに見えるため）。スマホは 130vw / 0.30。

**画面幅に連動させないこと。** 連動させると、広い画面ほど輪が余白へ散らばります。
ここは検証（`tests/run.mjs` の「お礼ページの水の輪」）で見張っています。

## 気をつけること

- **素材そのものを加工しないでください。** 明るさや大きさの調整は
  すべて CSS 側（`src/styles.css` の「応援ページ」ブロック）でやっています。
  `opacity` とマスクで、文字が読める濃さまで落としています。
- 背景は**中央がすいている**絵のほうが向いています。まん中に本文が載るので。
- 構図は2種類あります。**端から入ってくる絵**（水・葡萄）は画面の隅に置き、
  **中央が空いた輪の絵**（水の輪）は本文の列に合わせて置きます。
  輪を画面いっぱいに敷くと、腕が余白へ散らばって失敗します（上の記録）。
- **名前が違うと出ません。** `support-water-decorationd.png.png` のように
  文字が増えていると拾えないので、表のとおりに合わせてください。
  （拡張子だけは `.png` / `.webp` のどちらでも構いません）
- 1枚あたり 2MB を超えると、スマホの通信では目に見えて遅くなります。
  書き出すときに、長辺 1200px くらいまで小さくしておくと軽くなります。
