# リンクで配るための置き場所（渡す用）

サイト側の実装は**もう入っている**。置き場所を1つ用意して、
GitHub の設定を1か所いじるだけで出る。ここは、その手順。

> **設定するまで、リンクまわりは画面に1つも出ない。**
> お礼（チップ）と同じ扱いで、送り先が空なら機能ごと無い。
> だから、慌てて設定しなくてよい。

---

## 0. 何のためにやるのか

ファイルで配る道はもうある。置き場所が要らないのが利点だが、もらう側の手数が多い。

```
ファイル : 長押しで保存 → アプリを開く → 写真 → 「フレームをえらぶ」
           → さっき保存したものを探す → 調整 → 保存        （6〜7手）
リンク   : リンクを押す → 写真をえらぶ → 保存                （3手）
```

配る相手の年齢も慣れもばらばらなら、この差は大きい。

**両方残してある。** 置き場所を持ちたくなければ、ファイルの道だけ使えばいい。

---

## 1. 何が、どこへ行くのか（先に確かめておく）

| もの                     | どこへ行くか                                   |
| ------------------------ | ---------------------------------------------- |
| **利用者の写真**         | **どこへも行かない。** 端末の外に1バイトも出ない |
| 背景をけしたフレーム     | 「リンクを作る」を押したときだけ、置き場所へ   |
| 置きかた（名前・見え方） | 同上（フレームの中に入っている）               |

黙って送るものは1つも無い。画面にも、押す前にそう書いてある。

**90日で自動的に消える。** 掃除の仕組みを自分で持たない。

---

## 2. Cloudflare で置き場所を作る（10分ほど）

無料の範囲で足りる。目安は次のとおり。

| 項目       | 無料枠      | この用途では              |
| ---------- | ----------- | ------------------------- |
| 書き込み   | 1,000／日   | 1日1,000枠まで作れる      |
| 読み出し   | 100,000／日 | リンクを開く人の数        |
| 置ける量   | 1 GB        | 100KBのフレーム 約1万枚   |
| 期限       | 標準機能    | 90日で勝手に消える        |

> 無料枠の条件は向こうの都合で変わる。**始める前に、いまの条件を見ておく。**
> [Workers の料金](https://developers.cloudflare.com/workers/platform/pricing/)

### 手順（あなたがやること）

**この3つだけ。** あとは実装した側でやる。

1. Cloudflare のアカウントを作る（無料）

   ここは代われない。**あなたの名前で規約に同意する**手続きなので。

2. 手もとで、いちどログインする

   ```
   npx wrangler login
   ```

   ブラウザが開く。ここも代われない（あなたの資格情報なので）。

3. 入れ物を作って、出す

   ```
   npx wrangler kv namespace create FRAMES
   ```

   出てきた `id = "..."` を、`worker/wrangler.toml` の `PASTE_KV_ID` と
   置きかえる（直すのはその1行だけ。ファイルはもう置いてある）。

   ```
   npm run store:deploy
   ```

   `https://ae-frame-store.<あなた>.workers.dev` のような住所が出る。

**4. その住所を伝える。** 残りはこちらでやる（`src/lib/frameApi.ts` の
`BUILT_IN` に入れて、公開まで）。

---

## 3. サイトに載せる（こちらの作業）

`src/lib/frameApi.ts` の `BUILT_IN` に住所を入れて、押し出すだけ。
**GitHub の画面を触る必要は無い。**

```ts
const BUILT_IN = 'https://ae-frame-store.xxxx.workers.dev';
```

はじめは GitHub のリポジトリ変数にする案だったが、やめた。
それだと出すたびに GitHub の画面を触ってもらうことになる。
ここはただの公開URLで、隠す理由が無い（決済リンクとは事情が違う）。

### 出したあと、目で確かめること

- フレームを作って「みんなの見た目をそろえる」を入れると、**リンクを作る**が出る
- 押すとリンクができる
- そのリンクを**別の端末**で開くと、フレームが入った状態で開く
- 写真をえらぶと、背景けしを通らずに位置あわせへ着く
- 出来た画像が、配った側のものと同じ見た目になる

---

## 4. 止めるとき（あなただけでできる）

**荒らされたときに、直す人を待たなくていいようにしてある。**

GitHub の **Settings → Secrets and variables → Actions → Variables** で、

```
Name : FRAME_API
Value: off
```

を入れて、公開を1回走らせる。`off` は URL ではないので、
実装側が弾いて**リンクまわりが機能ごと消える**。コードは直さなくてよい。

- ファイルで配る道は残る（そちらは置き場所を使わない）
- すでに配ったリンクは開けなくなるので、**止める前に配った相手に知らせる**
- 置いてあるフレームも消すなら、Cloudflare 側で入れ物ごと消す

`usable` が URL でないものを弾くことは、検証が見ている
（「URLでない送り先は、通さない」）。守りを外すと落ちる。

---

## 5. 1枚だけ消したいとき（権利者から連絡が来たときなど）

リンクの末尾が合言葉。`https://.../#/f/abc123` なら `abc123`。

```
wrangler kv key delete --binding FRAMES "abc123"
```

ダッシュボードからも消せる（Workers & Pages → KV → 該当の入れ物）。

**消す口は、外から叩けるようにしていない。** 一覧も検索も置いていない。
リンクを知っている人だけが開ける形にしてある。

### 配った人が、自分で消す道は無い

**いまは作っていない。** 消せるのは置き場所を持っている人（あなた）だけ。

自分で消せるようにするには、作ったときに合言葉をもう1つ渡して、
それを持っている人だけが消せる形にする必要がある。
その合言葉をどこに置くかまで決めないと、**なくした人が消せない**まま、
消す口だけが外に開く。いまは 90日で消えることと、連絡をもらえば消すことで足りる。

間違えて作ってしまったリンクは、**配らなければ届かない**（一覧が無いので
たどり着けない）。どうしても気になるときは上のコマンドで消す。

---

## 6. 連絡の受け口と、上げてよいものの決まり（済み）

どちらも画面に入っている。**リンクまわりが出ているときだけ**出る。

| どこ                     | 何が出るか                                                     |
| ------------------------ | -------------------------------------------------------------- |
| 「リンクを作る」の直前   | 上げてよいものの決まり ＋ 相談・連絡の口                       |
| もらった人の画面         | 「このフレームについて知らせる」                               |

受け口は **https://kazuworks.net/contact**（すでにある窓口）。
新しく作らない。窓口が増えると、**見落とす場所も増える**。

決まりの文は、畳んだ規約にしない。**押す直前**に2行で置く。

> 自分で作ったフレームか、配ってよいと分かっているものだけにしてください。
> **他の人の絵やキャラクターを、許可なく配らないでください。**
> 連絡をもらえば消します。

もらった人の画面に置いたのは、**権利の連絡はフレームを見た人から来る**から。
押しどころにはしない（強調色は「画像をほぞんする」の1か所だけ、という決まり）。
そこは検証が数えている。

### いまも作っていないもの

- **一覧・検索**：作らない。棚に並べた瞬間「集めて見せている場所」になる
  （詳しくは `docs/frame-share-plan.md` の「置き場所を借りるときの設計」）
