# Stripe サポートに送る問い合わせ文

**この下の枠の中を、そのまま送る。** ここには内部の判断や経緯を書かない。
読むのは Stripe の担当者で、こちらの事情ではなく「該当するかどうか」を
答えられればいい人だから。

- `<公開URL>` を実際のURLに差し替える
- 掲載する文面は、実装（`src/components/Tip.tsx`）と一致していること
  （食い違うと `npm test` が落ちる）
- 返事は**書面で残す**。あとで「解決済み」の根拠になる
- **掲載文面は、省略せず全文を入れて送る。** ここで取りたいのは
  「この用途でいいですか」だけでなく、**「利用者に見せるのはこの文章です。
  この表示でいいですか」**の承認まで。要約すると、承認の対象が変わってしまう

## 送る文（ここから）

> 件名：提供済みサービスに対するチップの受け付けについて（事前確認）
>
> お世話になっております。
> 個人でブラウザ上のツールを1つ公開しており、その利用者から任意のお礼
> （チップ）を受け付けたいと考えています。**リンクを作成する前に**、
> 本用途で問題がないかを確認させてください。
>
> **■ 提供しているもの**
>
> - 画像を加工するブラウザツール（公開URL: <公開URL>）
> - **全機能を無料で提供しています。** 有償販売する商品・サービスや、
>   サブスクリプションはありません
> - 画像処理はすべて利用者の端末内で完結し、当方はサーバーを持ちません
>
> **■ 受け付けたいもの**
>
> このツールを**すでに利用していただいたこと**に対する、**任意のお礼（チップ）**
> です。金額は利用者が決めます。
>
> - 支払っても、利用できる機能は1つも増えません
> - 支払わなくても、全機能がそのまま利用できます
> - 特典・限定公開・先行公開など、お返しするものは一切ありません
> - 今後の制作物や資金の使途について、ページに一切記載しません
> - 目標金額・募集期間・支援者一覧も掲載しません
>
> **■ 実際に掲載する文面（全文）**
>
> ```
> 作った人にお礼を送る
>
> このツールはぜんぶ無料で使えます。
> このツールをすでに使っていただいたことへの任意のお礼として、好きな金額を送れます。
>
> 【送っても、送らなくても、できることは1つも変わりません。】
> 払うと増える機能はありません。払わないと使えない機能もありません。
> お返しするものもありません。
>
> ［ お礼を送る ］
>
> 金額を決める画面と支払いは、決済サービスの側でおこないます。
> カードの番号は、このサイトを通りません。
> ```
>
> **■ 確認したいこと**
>
> 1. 本件は、Stripe の定める「**すでに提供した商品・サービスに対するチップ**」の
>    要件に該当するという認識でよろしいでしょうか。
>
> 2. 当方のアカウントは、この用途で Stripe Payments を利用できる区分に
>    該当しますでしょうか。
>    （Stripe サービス利用規約（Services Terms）の利用資格に関する条項に、
>    「事業者ではない個人（個人事業主ではない個人を含む）は、Stripe の
>    事前承認を受けた場合にのみ利用資格がある」旨の記載があるため）
>
> 3. 過去に当アカウントに対して、規制対象業種に関連する可能性があるとの
>    照会をいただいた経緯があります。**現在は解決済みであり**、本用途での
>    利用に支障はないという理解でよろしいでしょうか。
>
> 4. 本用途で使用すべき機能（Payment Links / Checkout など）や、
>    掲載すべき表示事項について、指定・推奨があればご教示ください。
>
> ご確認のほど、よろしくお願いいたします。
